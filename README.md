# ESP32-S3 IoT Washing Machine Monitor

A washing-machine monitoring system using an ESP32-S3, ADXL345 accelerometer and Blynk Cloud.

## Features
- Real-time vibration monitoring
- Early warning when washing activity becomes low
- Physical push-button washing-cycle counter
- Drum-cleaning reminder after 15 cycles
- Blynk Cloud dashboard and push notifications

## Hardware
- Cytron Maker Feather AIoT S3
- ADXL345 accelerometer
- Push button
- Breadboard
